# Ebenezer Crochet

Página web tipo catálogo para un emprendimiento de muñecos tejidos a mano en Funza.

## Descripción
Este proyecto presenta productos de crochet de forma visual e interactiva, permitiendo ver información de los productos y contactar directamente mediante WhatsApp.

## Funcionalidades
- Catálogo de productos en tarjetas
- Tabla informativa de tipos de productos
- Galería de imágenes
- Formulario de contacto conectado a WhatsApp
- Interacción básica con JavaScript

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
